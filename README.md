### **AiKawach - Deepfake Detection Platform**  
🚀 **AiKawach** is a cutting-edge platform designed to detect deepfakes in **images and audio**, providing users with a reliable tool to verify the authenticity of digital content. Built with the **MERN stack, Redux, and Tailwind CSS**, AiKawach seamlessly integrates a **Python-based AI model** to deliver accurate deepfake detection.

## **Description**  
AiKawach leverages state-of-the-art **AI and deep learning techniques** to analyze images and audio files, determining whether they have been manipulated or generated using deepfake technology. The platform provides a **secure and efficient** way to validate digital content, mitigating the spread of misinformation.  

---

## **Features**  
✅ **Deepfake Detection:** Uses AI-based models to analyze images and audio for deepfake traces.  
✅ **Real-time Analysis:** Provides instant feedback on uploaded content.  
✅ **User Authentication:** Secure login and role-based access control using Redux.  
✅ **History & Reports:** Users can save and review past deepfake analysis results.  
✅ **Interactive UI:** Designed with React.js and Tailwind CSS for a seamless user experience.  
✅ **RESTful API:** Built with Express.js and integrated with the Python-based AI model.  
✅ **Scalable & Secure:** Utilizes MongoDB for efficient data storage and JWT for secure authentication.

## **Installation**  
### **Prerequisites**  
Make sure you have the following installed:  
- **Node.js** (v14 or higher)  
- **MongoDB** (Local or Cloud via MongoDB Atlas)  
- **Python** (3.8 or higher)  
- **Git**  

### **Clone the Repository**  
```bash
git clone https://github.com/Rahilsamani/AIKavach.git  
cd aikawach  
```

### **Backend Setup**  
1. Navigate to the backend directory:  
   ```bash
   cd server
   ```
2. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the backend server:  
   ```bash
   npm start
   ```

### **Frontend Setup**  
1. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the frontend server:  
   ```bash
   npm start
   ```
